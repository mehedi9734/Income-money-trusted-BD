Income money trusted BD — ডেমো ওয়েবসাইট
মালিক/ব্র্যান্ড: Ms Mehedi

চালানোর নিয়ম
1. ZIP Extract করুন।
2. index.html ওপেন করুন অথবা VS Code Live Server ব্যবহার করুন।
3. app.js-এর CONFIG অংশে প্যাকেজ ও পেমেন্টের তথ্য পরিবর্তন করুন।
4. Admin Panel-এ যেতে পেজের নিচের/মেনুর “অ্যাডমিন” অংশ খুলুন।
5. ডেমো অ্যাডমিন পাসওয়ার্ড: ChangeMe123!
6. লাইভে নেওয়ার আগে app.js-এর ADMIN_PASSWORD বদলালেও নিরাপদ হবে না—production-এ server-side authentication লাগবে।

অ্যাডমিন প্যানেলের ডেমো সুবিধা
- ওয়েবসাইটের নাম পরিবর্তন
- প্যাকেজ যোগ ও মুছে ফেলা
- অর্ডার তালিকা দেখা
- বিকাশ, নগদ, রকেট, ব্যাংক, Binance ও Crypto তথ্য পরিবর্তন

সীমাবদ্ধতা ও নিরাপত্তা
- এটি frontend demo; localStorage-এ ডেটা থাকে এবং browser storage মুছলে হারাতে পারে।
- অ্যাডমিন পাসওয়ার্ড ও লগইন সম্পূর্ণ client-side; এটি নিরাপদ নয়। যেকেউ browser devtools/localStorage পরিবর্তন করতে পারে। বাস্তব সাইটে backend, database, password hashing, role-based access, HTTPS, audit log ও server-side validation আবশ্যক।
- বাস্তব পেমেন্ট গেটওয়ে, KYC, টাকা উত্তোলন, ভিডিও বিজ্ঞাপন, ইমেইল মার্কেটিং বা রিলস আয়ের API সংযুক্ত নেই।
- কখনো পাসওয়ার্ড, OTP, PIN, seed phrase বা private key প্রকাশ করবেন না।
- আয় নিশ্চিত বলে প্রচার করবেন না; বৈধ স্পনসর/ক্লায়েন্ট, অনুমোদিত কাজ ও যাচাইকৃত পেমেন্ট ফান্ড থাকতে হবে।
- বাংলাদেশের আইন এবং প্রতিটি পেমেন্ট/সোশ্যাল প্ল্যাটফর্মের নীতিমালা যাচাই করে তারপর লাইভ করুন।
